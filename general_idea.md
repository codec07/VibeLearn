\# So, to start off, a General Overview



\-> This project is a GitHub repository (further would be expanded to a docs-type website) that is made for users to interactively learn Framework, Technologies and Programming Languages all from zero to mastery. Right now, the project focuses on helping people become an AI Engineer / Agentic AI Developer from scratch (like literally from Python Basics) though users can absolutely skip sections they've already studied, so, the workflow is simple and explained below



\-> WORKFLOW: User comes to the Repo -> Explores and Finally reads the Projects README.md to understand where to start from and how to use resources -> Opens a particular directory -> Inside the directory, they find books and docs written purely in markdown (.md) files -> They can start reading it comfortably (since GitHub provides markdown file support -> They find interactive working links to more resources or official pages and more -> They try out some of the examples their own and move ahead. 



\-> File and Folder System: Each Head topic / directory contains a guide.md (focused) which Guides the users on where to start, what prerequisites are expected and what they can expect to be able to build by the end of that course, following this would be sub-directories (not recommended but if a main directory gets too clustered due to many .md files, use this approach) and then the main files {topic}.md, these would be the main docs-type markdown and rich text files.
